# 🖼 assets — IMAGES, STYLES, SCRIPTS

| Folder | What's inside | Edit? |
|---|---|---|
| `images/` | Logos, background photo, browser-tab icon | Upload new images here |
| `images/speakers/` | **Speaker photos** | Upload here, then write the file name in `_data/en/08-speakers.yml` and `_data/mn/08-speakers.yml` |
| `css/style.css` | Colours, fonts, layout | Not needed |
| `js/main.js` | Mobile menu and countdown | Not needed |

**Changing the background photo:** upload the new photo to `images/`, then write its file name in `_config.yml` → `hero_image:`
