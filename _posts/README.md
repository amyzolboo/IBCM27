# 📰 _posts — ENGLISH NEWS

Each file here is one **English news post**. The newest 3 appear on the home page.
(Mongolian news is in `mn/_posts/`.)

## Add a news post
1. Click **Add file → Create new file**.
2. Name it with the date first: `2027-01-15-call-for-abstracts.md`
3. Paste this and change the text:

```
---
title: Call for abstracts is now open
lang: en
ref: call-for-abstracts
---
Write the announcement here.
```

4. Click **Commit changes**.
5. Make the Mongolian version in `mn/_posts/` with the **same file name and same `ref:`**, but `lang: mn`.
   (The same `ref` connects the two, so the EN / МН switch works.)
